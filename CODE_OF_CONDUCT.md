# Code of Conduct

AirVault contributors are expected to make participation respectful, safe, and productive.

Be considerate, discuss technical disagreements with evidence, respect privacy, and avoid harassment, discrimination, threats, or disclosure of another person's private information. Project maintainers may edit or remove contributions and restrict participation when conduct harms the community or project security.

Report conduct concerns privately through the repository owner's GitHub profile. Do not use a public issue when the report contains personal or sensitive information.
